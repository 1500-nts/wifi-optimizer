# Wi-Fi Network Optimizer

A Python simulator that models a small Wi-Fi network, **monitors** its condition, **detects**
inefficiencies (channel interference, congestion, weak signal, overloaded access points), and
**dynamically reconfigures** the network to improve performance, then **measures** the result.

```
Monitor  ->  Analyze  ->  Optimize  ->  Measure
```

## Features

- Wireless network model: path loss, shadowing, co-channel interference, airtime sharing, rate adaptation
- Metrics: throughput, latency, packet loss, channel utilisation, RSSI, interference, fairness
- Configurable **Efficiency Score**: `w1*throughput - w2*latency - w3*loss - w4*interference - w5*congestion`
- Three optimization mechanisms:
  - **Dynamic channel selection**
  - **Load-aware AP selection** (RSSI, spare capacity, utilisation, interference, latency)
  - **Transmit-power tuning**
- Experiments: static before/after, robustness over 20 random topologies, dynamic scenario
  (moving users, traffic surge, new interferer), load and user-count sweeps
- Automatic graphs (PNG), CSV and JSON output
- Unit tests (pytest)

## Requirements

- Python 3.10+
- `numpy`, `matplotlib`, `pytest` (see `requirements.txt`)

## Installation

```bash
git clone <your-repo-url>      # or unzip the project
cd wifi-optimizer
python -m venv .venv           # optional
# Windows PowerShell:  .\.venv\Scripts\Activate.ps1
# macOS / Linux:       source .venv/bin/activate
python -m pip install -r requirements.txt
```

## Usage

```bash
python run.py all         # every experiment (recommended first run)
python run.py static      # one before/after experiment + topology + change log
python run.py dynamic     # time-varying scenario
python run.py sweep       # load vs throughput, users vs latency
```

| Option | Meaning |
|---|---|
| `--seed N` | Fixed random seed (reproducible results). Default `1` |
| `--random` | New random seed every run (different layout, traffic and event times) |
| `--steps N` | Time steps in the dynamic scenario (default 60) |
| `--aps N` | Number of access points (default 2) |
| `--clients N` | Number of wireless clients (default 10) |
| `--no-power` | Disable transmit-power tuning |
| `--out DIR` | Output folder (default `results`) |

Examples:

```bash
python run.py dynamic --random
python run.py all --seed 7 --clients 20 --aps 3
python run.py dynamic --seed 6751239     # reproduce a previous --random run
```

Run the tests:

```bash
python -m pytest -q
```

| File | Content |

## Example results

Default settings, averaged over 20 random topologies (all values generated by the simulator):

| Metric | Unoptimized | Optimized |
|---|---|---|
| Throughput | 40.0 Mbps | 88.4 Mbps |
| Latency | 228 ms | 9 ms |
| Packet loss | 20.4 % | 0.5 % |
| Channel utilisation | 100 % | 59 % |
| Interference | 17.9 dB | 0.0 dB |

## How it works

1. **Build:** APs and clients are placed from a random seed; all APs start on channel 1 and clients join the strongest signal.
2. **Monitor:** the model computes RSSI, SINR, airtime demand, contention, loss and latency.
3. **Analyze:** threshold rules flag overloaded APs, congested channels, co-channel interference, poor signal and load imbalance.
4. **Optimize:** channels, client associations and transmit power are changed one at a time; a change is kept only if the global Efficiency Score improves (a hysteresis margin prevents clients from flip-flopping).
5. **Measure:** the network is evaluated again and compared with the starting state.

See `GUIDE.md` for the full explanation.

## Customization

Edit `wifi_optimizer/config.py` to change the number of APs and clients, channels, radio parameters,
thresholds, and the Efficiency Score and AP-selection weights. Use a fixed `--seed` when comparing settings
so the only difference is your change.

## Limitations

- An analytical flow-level model, not a packet-level simulator; trends are reliable, absolute numbers are indicative.
- Greedy search may miss the global optimum.
- Parameters (weights, thresholds, path-loss exponent) are assumptions; run a sensitivity analysis before drawing strong conclusions.
